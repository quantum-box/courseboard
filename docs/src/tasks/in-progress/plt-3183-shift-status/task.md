# PLT-3183 シフト表の状態反映

## 原因

Field と CourseBoard API は `employmentStatus` と日別の `availability.status` を保持していたが、シフト表の view model が状態を落としていた。

- `suspended` は行を作る前に除外され、`inactive` は行へ残っても表示されなかった。
- 明示的な `available` は `none` に変換され、表示と連続稼働日の判定から外れていた。
- 連続稼働日は割当だけで判定され、稼働可能な日別状態を参照していなかった。

別々の API や保存処理ではなく、同じシフト表 projection 層の欠陥である。`buildShiftRow` に雇用状態と日別状態の変換を集約し、表示と連続稼働日の判定が同じ変換結果を使うようにする。

## 完了条件

- `inactive` と `suspended` のキャディを行から落とさず、日本語の状態を表示する。
- 明示的な `available` を略記「可」で表示する。
- `available`、午前のみ、午後のみ、軽作業を連続稼働日に含める。
- 月境界をまたぐ判定のため、日別状態も割当と同じ前後 6 日を取得する。
- 未知の日別状態は予定なしに潰さず「状態を確認」と表示し、稼働日へは推測で含めない。
- 未保存離脱は「保存していない休みの希望が失われる」と説明する。

PLT-3181 の年月入力部品には依存せず、`origin/main` から独立した PR とする。
