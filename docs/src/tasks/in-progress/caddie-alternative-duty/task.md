# キャディの別業務割り当て

ラウンドの割り当てがない日のキャディに、コース整備などの別業務を割り当てられるようにする。

## 背景

出勤が確定していてもティーシートが埋まらない日、そのキャディはボード上では手すきに見え、
実際には庭仕事に出ている。どちらなのかを配置画面が何も言わない状態だった。
CourseBoard には「ラウンド以外の業務」を記録する場所が一切なかった。

## 決定事項

1. **割り当ては日次の配置画面（キャディ > 配置）で行う。** 当日・前日の運用に合わせる。
   月次シフト表には手を入れない。
2. **業務種別はマスタ管理。** 設定画面（`SettingsPage`）の「キャディの別業務」で追加・
   並べ替え・削除する。割り当て時は選択式＋自由記述の補足。
3. **別業務は時間帯で入れる。** 開始・終了を指定でき、未指定は終日。1日に複数入れられる
   （午前コース整備・午後練習場）。同じキャディの時間が重なる入力は拒否する。
4. **その時間帯だけラウンド供給から外す。** 自動配置・推薦・手動指名・付け替えは
   「ラウンドの占有時間と別業務の時間が重なるか」で判定し、集計は正午を境に
   潰れた半日を引く。午前だけ別業務の人は、午後1ラウンドぶんとして数える。

## データの置き場所（ADR-0005 / ADR-0009）

ゴルフの語彙なので CourseBoard ローカル DB に持つ。Field には出さない。

- `golf_caddie_duties` — 業務種別のピックリスト（tenant, label, position）
- `golf_caddie_duty_assignments` — 1キャディ×1日×1時間帯（`start_minute` / `end_minute` は
  クラブの0時からの分。0–1440 が終日。unique: tenant, date, caddie, start_minute）

`golf_caddie_shifts` の列にはしない。**月の再生成が `generated` 行を書き換えるため、
別業務が翌週の生成で消える。** 割り当ては業務種別を id ではなく **ラベルのスナップショット**
で持つ。マスタから業務を消しても、過去の日が「何をしていたか」は書き換わらない。

## 割り当てのルール

- 時間帯は半開区間。11:00-12:00 と 12:00-15:00 は重ならず、同じ日に並べられる。
- 同じキャディの時間が重なる入力は拒否する（同じ開始時刻での再入力は訂正として扱う）。
- その時間にラウンドを持っているキャディには入れられない（先にラウンドを外す）。
  ラウンドの占有は既定 270 分。
- 逆に、その時間に別業務が入っているキャディはラウンドに指名できない。
  **重ならない時間のラウンドは通る** — 午前別業務・午後ラウンドが成立する。
- マスタにない業務名は拒否する。

### 集計での数え方

供給はラウンド数で数えるので、時間帯は「潰した半日」として引く（正午が境。
`shift_covers_tee_time` が半日希望を読むのと同じ線）。

- コース別供給: `rounds_capacity` を空いている半日の数で頭打ちにする。
  両方潰れていればシフトごと落とす（出勤者数からも未配置からも消える）。
- 販売可能枠: 出勤希望のステータスを空き半日と突き合わせて狭める
  （午前別業務 → 午後のみ扱い）。両方潰れていればその人を数えない。
- 自動配置: 別業務の時間帯を `PlannableCaddie.busy` に足す。ラウンドの占有と
  同じ扱いになるので、planner 側の変更は不要。

## API

認可は配置と同じ action を使う（マニフェスト変更なし）。

- `GET/PUT /v1/course/caddie-duties` — 業務種別マスタ
  （`ListCaddieAssignments` / `ManageCaddieAssignments`）
- `GET /v1/course/caddie-duty-assignments?from&to`
- `POST /v1/course/caddie-duty-assignments`（body に `startTime` / `endTime` の `HH:MM`。
  両方省略で終日、片方だけはエラー）
- `DELETE /v1/course/caddie-duty-assignments/{dutyId}`（1日に複数あるので行 id で外す）

## 供給への反映箇所

- `auto_assign_caddies.rs` — 候補から除外
- `list_caddie_recommendations.rs` — 候補から除外
- `create_caddie_assignment.rs` — 手動指名を拒否
- `get_course_caddie_supply.rs` — その日の確定シフトを集計対象から落とす
  （コース capacity と「未配置」の両方から消える）
- `get_caddie_supply.rs` — 販売可能なキャディ付き枠から落とす

## 画面

- 配置画面に「別業務」パネル。時間帯つきの行（`08:00–12:00` / 終日・業務バッジ・補足・解除）と、
  手の空いている時間があるキャディの人数の1行。名前はシートの中で選ぶ（手すきが40人並ぶと、
  実際に割り当てた数人が埋もれるため）。候補には「午前が空き」などを添える。
- シートは「終日」チェック（既定 ON）を外すと開始・終了を指定できる。重なりと前後逆は
  保存前に画面側でも止める。
- 設定画面に「キャディの別業務」パネル（業務種別の追加・削除・並べ替え）。

## 同日のラウンド付け替え（追加）

別業務と同じ画面の続きとして、すでに配置済みのラウンドを同日内で付け替えられるようにした。
これまでは「取消 → 再指名」しかなく、行とそこに紐づくもの（推薦スコア、備考、Field の記録）が消えていた。

- 対象は **同日のみ**。判定材料（誰が出ているか、誰が別業務か、シフトがそのティータイムを
  カバーするか）はすべて日単位で読んでおり、日をまたぐ移動は別の日の答えで判定してしまう。
- 変えられるのは **担当キャディ / 対象の組 / その両方**。
- ガードは手動指名と同じものを共有する（`src/course/usecase/caddie_round_guards.rs`）。
  移動する行自身は競合から除外する。動かす当人が「その組をすでに持っている」ことを理由に
  拒否されては動かせない。
- **入れ替え（2人のスワップ）は1操作にしない。** Field への書き込みは1件ずつで、
  途中で失敗すると「1組に2人・1組に0人」が残る。先に片方を外す運用にして、
  埋まっている組を選んだときは理由を出す。
- 料金はキャディのランクで再計算する。ランクの違う人が引き継いだ行が前任者の単価のまま
  給与表に出るのを避ける。
- ステータスは変えない（完了済みの行を別の組に付け替えても完了のまま）。

`PUT /v1/course/caddie-assignments/{id}/reassignment`（`ManageCaddieAssignments`）。
画面は「この日の割当」表の各行の「付け替え」ボタン → シート（組・担当キャディ）。
キャディ個人の履歴からは出さない（その画面はティーシートを持っておらず、月をまたぐため）。
