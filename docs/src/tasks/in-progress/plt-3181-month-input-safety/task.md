# PLT-3181 月入力で業務画面を落とさない

## 対象

- シフト表、キャディ給与、月次精算、日別予算の4つの `type="month"` を共通 picker に置き換える。
- 入力境界で `2026-2`、`2026-02`、全角数字を `YYYY-MM` に正規化する。
- 空文字、不正文字列、月 00 / 13 は直前の有効値を保持し、描画関数へ渡さない。
- シフト表と給与 section を error boundary で隔離する。
- API validator の内部名を利用者向けエラーに表示しない。

## 月・日付入力の棚卸し

自由入力可能だった月欄は次の4箇所で、すべて本 task の共通 picker 対象とする。

- `ShiftBoardPage.tsx` — シフト表
- `CaddiesPage.tsx` — キャディ給与
- `SettlementPage.tsx` — 月次精算
- `BudgetsPage.tsx` — 日別予算

日付欄は10箇所（キャンセル料期日、料金シミュレーター2、タイムライン、日別予算、コース日程3、キャディ配車・勤怠）ある。いずれも plain text ではなく `type="date"` の native date picker であり、月文字列を直接 renderer に渡す経路はない。

## 回帰

- 不正文字列、空文字、月 00 / 13、全角数字で例外を投げない。
- `2026-2` と `2026-02` を同じ値として扱う。
- 無効値では直前の有効な月を保持する。
- `yearMonth` など validator の内部名を日本語 UI に出さない。
