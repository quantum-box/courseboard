# 既存キャディの本人ごとの単価をランク単価に寄せる

## Links

- [PLT-3346](https://linear.app/issue/PLT-3346)
- 関連: [PLT-3348](https://linear.app/issue/PLT-3348)（ランク単価の変更履歴）、[PLT-3349](https://linear.app/issue/PLT-3349)（過去配置の打刻額）、[PLT-3264](https://linear.app/issue/PLT-3264)（名簿投入）

## 背景

ランク単価（#183）より前に登録したキャディは、登録フォームで単価が必須だったため全員 `base_fee_amount > 0` を持つ。
給与計算は「本人ごとの単価 > 0 ならそれ、0 ならランク単価」なので、ランク単価を決めても誰にも効かない。

寄せる（本人ごとの単価を 0 にする）と、ランク単価との差だけ支給額が変わる。本人ごとの単価はベテランを個別条件で
雇うために残している仕組みで（`caddie_rank_fee.rs` 冒頭）、**誰を寄せるかは現場の取り決め**でありコードでは決めない。

以前のコメントで「変更履歴が残る形ができるまで一括移行はしない」「履歴は Field に置く」とされていた。
その後 ADR-0009 / ADR-0010 でゴルフ固有の設定・履歴は CourseBoard ローカル DB に置くと決まったため、
履歴は `golf_caddie_own_fee_changes` に置く。ランク単価表そのものの履歴（PLT-3348、`golf_caddie_rank_fee_changes`）とは別のテーブル。

## やったこと

- 給与画面に「ランク単価に寄せる」シートを足した（`CaddieFeeAlignmentSheet`）。
  - 本人ごとの単価を持つキャディを「下がる / 上がる / 変わらない」に分けて並べる（下がる人が先頭）。
  - **初期選択は「変わらない」人だけ。** 上がる・下がるは人が選ぶ。下がる人を選ぶと減額の合計を警告する。
  - ランク単価が 0 のランクには寄せられない。
  - 寄せると過去月の表示額も変わることを明示する（給与は現在単価で再計算するため。PLT-3349 の範囲）。
  - 理由を入れられ、変更履歴に残る。
- `GET/POST /v1/course/caddie-fee-alignment`
  - プレビューは `ListCaddies` + `ListCaddieRankFees`、実行は `ManageCaddies` + `ManageCaddieRankFees` を usecase 冒頭で要求。
  - **CourseBoard ローカルにランク単価が保存されていないテナントでは実行を 409 で拒否。**
    extension config のフォールバック値やコードの既定値（12,000 / 11,000 / 10,000 / 9,000）は合意された給与額ではないため。
  - 画面に出ていた単価（`expectedOwnFee`）と現在値が違うキャディは寄せない（`own_fee_changed`）。
  - 1 人ずつ Field の caddie profile を更新する。1 人の失敗で残りを止めない。認可を失った場合だけ全体を止める。
- `golf_caddie_own_fee_changes`: 変更前の単価、寄せた時点のランク単価、理由、実行者（token の `sub` と username）、日時。
  Field 更新の前に未確定行を書き、更新成功で確定する。未確定行は一覧に出さない。

本番 DML は使わない。移行は運用者が画面から行う。

## 現場に決めてもらうこと（コードでは決めない）

- 正式なランク単価（保存するまで寄せられない）
- 誰を本人ごとの単価のまま残すか（下がる人の扱い）
- 寄せる時期（寄せると過去月の表示額も変わる。締めた月の CSV を出し直す前に寄せるかどうか）
