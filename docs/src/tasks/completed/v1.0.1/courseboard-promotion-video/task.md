# CourseBoard プロモーション動画

## 概要

CourseBoard のゴルフ場運用を短時間で伝える、約 30 秒のプロモーション動画を Remotion で制作する。
受付、キャディ、予約、顧客管理の順に現場の仕事を区切り、キャディの需給、ラウンド配置、別業務、シフト、出勤・給与がひとつの流れにつながる点を、デモ画面とブランド資産を使って表現する。
成果物は再レンダリング可能なソースと MP4 とし、実在顧客の個人情報や未確認の効果数値は使わない。

## 対象範囲

- 1920 × 1080、30 fps、約 30 秒の横長動画
- CourseBoard のロゴ、キャディ配置画面、キャディ運用のデモ画面の活用
- 日本語の短い訴求コピーとオリジナルの簡易 BGM
- Remotion のプレビュー、型検査、静止画確認、MP4 レンダリング

## 対象外

- 製品 UI や API の変更
- 実在顧客データ、実績値、導入効果の数値表現
- ナレーション、外部の有償音源、第三者の映像素材
- 本番環境への公開や配信

## 実装

1. ブランド資産とデモ安全な画面素材を選定する。
2. 受付、キャディ、予約、顧客管理の順で、セクションごとに背景色と区切り画面を持つ構成を Remotion で実装する。
3. 音声と映像のフェード、画面遷移、字幕の可読性を整える。
4. 型検査、静止画、動画レンダリング、メディア情報を確認する。

## 完了条件

- `video/out/courseboard-promo.mp4` を再生可能な H.264 MP4 として生成できる。
- 1920 × 1080、30 fps、約 30 秒である。
- 画面内の文言と素材に実在顧客の個人情報が含まれない。
- ソースから同じ成果物を再レンダリングできる。

## リスクと残作業

- リポジトリ内の画面素材だけでは全機能を実写で示せないため、訴求範囲をキャディ運用中心に絞る。
- 公開先ごとの縦長・正方形バリエーションやナレーションは別作業とする。

- `npm run type-check`: 成功
