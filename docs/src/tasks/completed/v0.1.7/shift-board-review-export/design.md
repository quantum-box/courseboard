# シフト表レビュー対応 設計

## 目的

シフト案を確定済みシフトから明確に分離し、保存前に安全に比較できるようにする。同時に、月次表としての行・曜日の読みやすさとプロフィール補助情報の表示安定性を改善する。

## 方針

### シフト案の確認

既存の `POST /v1/course/caddie-shift-plans/{yearMonth}/preview` と確定用 POST は変更しない。preview のレスポンスはページ上の確定表へ合成せず、モーダル内にだけ表示する。モーダルには生成結果の要約、差分表示付きの読み取り専用シフト表、確定と破棄の操作を置く。確定成功後にモーダルを閉じて確定表を再取得する。

月間31日とキャディ一覧をできるだけ広く確認できるよう、モーダルはブラウザの表示領域全面を使う。ヘッダーと確定・破棄・PDF操作は固定し、要約とシフト表を中央のスクロール領域に置く。

閉じる操作は破棄と同じ扱いとし、サーバーへの書き込みは行わない。確定処理中は閉じる操作を無効にして、結果不明のまま表示だけが消える状態を避ける。対象月を変えた場合も既存どおりプレビューを破棄する。

### 表の視覚状態

- 平日ヘッダーは不透明な淡いグレー、土曜列は淡い青、日曜列は淡い赤にする。ヘッダーはすべて下地が透けない不透明色とし、表本体はセルの勤務・休み・警告色を置き換えず、曜日色と状態色を同時に読めるようにする。
- 月間表の各日セルは勤務状態の記号だけを表示し、コース略称は重ねない。コース配置データと日別編集画面は維持し、CSV・Excelには運用データとして残す。
- `inactive` / `suspended` の行は状態テキストを視覚的には追加せず、行全体を低彩度のグレーにする。状態名はスクリーンリーダー向けテキストとして残す。
- 表末尾4行のプロフィールカードは名前の上側へ開く。カードの内容とプロフィール遷移は変更しない。

### PDF保存と印刷

確定表とシフト案の双方に「エクスポート」を置き、ブラウザ標準の印刷ダイアログを開く。利用者は同じダイアログでプリンターまたは「PDFとして保存」を選べるため、PDF生成APIや新しいファイル保存先は追加しない。ブラウザの通常の印刷ショートカットを使った場合も、確定表の印刷専用レイアウトを出す。

画面の表は横スクロールとsticky列を前提にしているため、そのDOMをそのまま印刷しない。全31日を必ず含む非対話の印刷専用表をbody直下へ一時的に描画し、A3横1枚に月間一覧を配置する。画面で表示中の週やスクロール位置は印刷結果へ影響しない。シフト案から出力した場合は、タイトルを「シフト案」とし、変更セルの破線も保持する。印刷操作はデータを書き換えない。

### CSV・Excelエクスポート

「エクスポート」をメニュー化し、PDF・印刷、CSV、Excelを同じ入口から選べるようにする。確定表とシフト案のどちらからでも出力でき、ファイル名はそれぞれ `キャディシフト表_N月` / `キャディシフト案_N月` として混同を防ぐ。出力はブラウザ内で完結し、APIへの書き込みは行わない。

CSVはキャディ、雇用状態、連続勤務日数、月内全日を列にしたUTF-8 BOM付きデータとし、日本語版Excelで直接開いても文字化けしないようにする。ExcelはHTMLやCSVへ拡張子だけを付けるのではなく、Office Open XML形式の実ファイルを生成する。タイトル、注記、曜日ヘッダー、勤務状態色、停止中行のグレー表示を持たせ、先頭3列と先頭3行を固定し、フィルターとA3横印刷設定を付ける。案の変更・固定状態はセル本文の印で失われないようにする。

## 代替案

- 本表を提案内容に差し替える現状方式は、比較対象を失うため採用しない。
- 提案と確定を左右2表で常時並べる方式は、31日分の横幅を持つ表では比較しづらく、通常時の画面も重くなるため採用しない。
- プロフィールカードを document body へポータルする方式はあらゆる境界に強いが、位置追従とフォーカス管理の変更範囲が大きい。今回の縦方向の切れには上向き表示で十分なため見送る。

## 影響範囲

`desktop` のシフト表コンポーネント、翻訳、スタイル、ローカルfixture、関連テストのみ。ローカルfixtureには確定データを書き換えないpreviewレスポンスを追加する。PDF保存、印刷、CSV、Excel生成はブラウザ内で完結する。実API、DB、認可、Field連携、確定シフト生成ロジックは無変更。長期的なアーキテクチャ判断ではないためADRは追加しない。

## 検証

コンポーネントテストで本表とモーダル内プレビューを区別し、確定表と案がそれぞれ印刷・CSV・Excelへ渡ることを検証する。CSVはBOMと引用符処理、ExcelはZIP内のワークシート、固定行列、フィルターを自動検証する。生成したExcelは表計算エンジンへ読み戻してPNGへレンダリングし、日本語、曜日色、勤務状態色、停止中行を目視確認する。ローカル画面では、デスクトップ幅と狭い幅の双方で土日列、停止中行、モーダル内の横スクロール、最下段カードの表示方向を確認する。印刷媒体をPDFへ出力してPNGへレンダリングし、全日・全行、色、文字切れ、1ページ収まりを目視確認する。
