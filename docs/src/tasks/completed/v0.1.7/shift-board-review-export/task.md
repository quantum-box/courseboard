# シフト表の確認と出力を改善する

## 背景

シフト表の運用レビューで、シフト案が確定表をその場で置き換えて比較対象を失うこと、停止中キャディだけ行高が変わること、曜日や再読み込み状態が読み取りにくいこと、最下段のプロフィールカードが切れることが確認された。あわせて、月間表を印刷・PDF・CSV・Excelへ出力したいという要望があった。

Linear issue は未紐付けであり、2026-08-17のブラウザレビューを入力とした。詳細は [設計](design.md) を参照する。長期的なアーキテクチャ判断ではないためADRは追加していない。

## 実装範囲

- シフト案を全画面モーダルに分離し、確定するまでは本表を書き換えない。
- 停止中キャディの行を同じ高さのままグレーへトーンダウンし、状態名は支援技術向けに残す。
- 平日・土曜・日曜のヘッダーへ不透明な背景色を付け、末尾付近のプロフィールカードを上向きに開く。
- 月間表と印刷表の日セルからコース略称を外し、配置データ、日別編集、CSV・Excelのコース情報は維持する。
- 確定表とシフト案から、A3横のPDF・印刷、UTF-8 BOM付きCSV、実体がOffice Open XMLのExcelを出力する。候補名は `キャディシフト表_N月` / `キャディシフト案_N月` とする。
- Cmd+Rなどの再読み込み時に、左下で進行中・成功・失敗をアニメーション付きで通知する。

実API、DB、認可、Field連携、確定シフト生成ロジックは変更していない。

## 検証

- `desktop`: `npm run test -- --minWorkers=1 --maxWorkers=4` で全82ファイル・704件のテスト、`npm run type-check`、`npm run build`、`git diff --check` が成功した。buildには既存のchunk size警告が残る。
- ローカル画面をブラウザ自動操作CLIで1266×979と狭い幅にして確認し、30pxの行高、停止中行、平日・土日列、全画面モーダル、最下段カード、左下の再読み込み通知を確認した。
- シフト案のpreviewでは確定表を書き換えず、確定操作時だけ保存POSTが走ることをコンポーネントテストで確認した。
- 31日・40人のA3横PDFをPNGへレンダリングし、全列・全行、曜日色、勤務状態色、停止中行、文字切れ、1ページ収まりを目視確認した。
- Excelを表計算エンジンへ読み戻して日本語セルと書式を検査し、PNGレンダリングでも表示を確認した。

認証済み本番は未デプロイのため未確認。ローカルfixture確認は本番確認の代替ではない。
