# キャディ割当シミュレーション

キャディごとの勤務条件、身体負荷、報酬希望、公平性を
CourseBoard の割当へ反映するための要件検討資料。

[キャディ割当シミュレーション（Excel）](./caddie-assignment-simulation.xlsx)

## 収録内容

- 架空キャディの勤務区分、最大担当組数、最大組人数、希望組人数。
- 架空ラウンドの開始時刻、人数、コース、所要時間。
- Hard 条件を先に適用し、希望と公平性を点数化する割当例。
- 個人別の担当数、4 人組数、見込バックの集計。
- 20 種類のシチュエーションと、CourseBoard での扱い、
  自動割当への影響、オペレーター表示、保存先の整理。

## 前提と制約

- 登場人物と予約はすべて架空である。
- 4 人組の追加バック 2,000 円はシミュレーション上の仮定である。
  正式な給与ルールとして採用する場合は、組人数別単価の要件を別途確定する。
- Excel の割当は入力順に候補を決める逐次ヒューリスティックであり、
  CourseBoard 実装の最終最適化アルゴリズムではない。
- 安全、勤務不可、時間重複などの Hard 条件は自動上書きしない。
  希望は未達を許容し、公平性は未割当を増やさない範囲で調整する。
- 病名、介護等の個人事情は計算入力にせず、最大組人数、勤務可能時間、
  対象コース、有効期限など、配置に必要な制限だけを扱う。

## 責務境界

- 一般的なスタッフ profile、勤務可否、出退勤は Field を正とし、
  CourseBoard の画面から汎用 API を利用する。
- 組人数希望、ゴルフコース適性、ラウンド負荷などのゴルフ固有ルールは
  CourseBoard が所有する。
